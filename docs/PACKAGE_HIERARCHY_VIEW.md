# 元模型包层级展示功能说明

## 功能概述

在元模型管理页面新增了"元模型包"Tab，提供层级展示功能，可以通过元模型包查看其包含的实体元模型和关系元模型。

## 实现内容

### 1. 新增状态管理

- `packages`: 存储所有元模型包列表
- `packageDetails`: 存储每个包的详细信息（实体和关系元模型）
- `expandedPackages`: 存储当前展开的包列表

### 2. 新增功能函数

- `loadPackages()`: 加载所有元模型包列表
- `loadPackageDetails(packageName)`: 加载指定包的详细信息（实体和关系元模型）
- `handlePackageExpand(packageName)`: 处理包展开事件

### 3. UI 组件

使用 `Collapse` 组件实现层级展示：

```
元模型包
├── 包1 (code_metadata)
│   ├── 包信息（名称、路径、采集器类型、部署时间等）
│   ├── 实体元模型列表
│   │   ├── CodeProject@v1 [启用] 查看详情
│   │   ├── CodeFile@v1 [启用] 查看详情
│   │   └── ...
│   └── 关系元模型列表
│       ├── CONTAINS@v1 [启用]
│       └── ...
├── 包2 (relational_database)
│   └── ...
└── ...
```

### 4. 包信息展示

每个包展开后显示：

- **基本信息**：
  - 包名
  - 路径
  - 采集器类型（如果有）
  - 部署时间
  - 元数据（名称、版本、描述等）

- **实体元模型列表**：
  - 使用 `List` 组件展示
  - 显示类型、版本、标签、描述
  - 显示启用/禁用状态
  - 提供"查看详情"按钮

- **关系元模型列表**：
  - 使用 `List` 组件展示
  - 显示类型、版本、标签、描述
  - 显示源类型和目标类型
  - 显示启用/禁用状态

### 5. 交互功能

- **展开/折叠**：点击包标题可以展开/折叠查看详情
- **懒加载**：只有在展开时才加载包的详细信息
- **查看详情**：点击实体元模型的"查看详情"按钮，可以查看完整的模型信息
- **自动刷新**：上传新包或重新加载注册表后，自动刷新包列表

## 使用方式

1. **查看包列表**：
   - 打开元模型管理页面
   - 切换到"元模型包"Tab
   - 可以看到所有已部署的元模型包

2. **查看包详情**：
   - 点击包标题展开
   - 查看包的基本信息
   - 查看包内的实体元模型和关系元模型

3. **查看实体详情**：
   - 在实体元模型列表中，点击"查看详情"按钮
   - 弹出模态框显示完整的实体元模型信息

## 技术实现

### 前端组件

- `Collapse`: 用于展示可展开/折叠的包列表
- `List`: 用于展示实体和关系元模型列表
- `Descriptions`: 用于展示包的详细信息
- `Tag`: 用于显示标签和状态
- `Badge`: 用于显示启用/禁用状态

### API 调用

- `api.metamodel.listPackages()`: 获取所有包列表
- `api.metamodel.getPackage(packageName)`: 获取指定包的详细信息

### 数据流

1. 页面加载时调用 `loadPackages()` 获取包列表
2. 用户展开包时，调用 `loadPackageDetails()` 获取详细信息
3. 详细信息缓存到 `packageDetails` 状态中，避免重复请求
4. 上传新包或重新加载注册表后，清空缓存并重新加载

## 注意事项

1. **性能优化**：
   - 使用懒加载，只在展开时加载详细信息
   - 缓存已加载的包详情，避免重复请求

2. **数据同步**：
   - 上传新包后自动刷新包列表
   - 重新加载注册表后清空缓存并刷新

3. **错误处理**：
   - 如果包没有实体或关系元模型，显示空状态提示
   - API 调用失败时显示错误消息
